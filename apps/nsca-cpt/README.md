# NSCA-CPT 試験対策アプリ

NSCA-CPT（NSCA認定パーソナルトレーナー）の受験対策用 Web アプリです。
**毎日続けられる「習慣化」** を最重要目標に、弱点優先の出題（Leitner 方式）と
本番形式の模試で合格を目指します。

- **技術スタック**：Next.js(App Router) + TypeScript + Tailwind CSS
- **保存**：localStorage（保存層は抽象化済み。将来のDB化が容易）
- **PWA**：インストール可能・オフラインで問題演習が動く
- **デプロイ**：静的書き出し（`output: "export"`）で Vercel などに配信可能

> ⚠️ **免責**：収録問題はオリジナルの学習用であり、公式問題の再現ではありません。
> 最終確認は必ず公式テキスト（第3版）で行ってください。出題比率・合格ライン（70%）・
> 試験日は設定値（概算）です。最新の公式情報でご確認ください。

## 1. セットアップ（`npm run dev` で起動）

前提：Node.js 18 以上（推奨 20 / 22）。

```bash
# このアプリのディレクトリへ移動
cd apps/nsca-cpt

# 依存関係をインストール
npm install

# 開発サーバーを起動 → http://localhost:3000
npm run dev
```

その他のコマンド：

```bash
npm run build   # 本番ビルド（静的サイトを out/ に書き出し）
npm test        # 主要ロジックの単体テスト（弱点優先・模試比率）
npm run lint    # ESLint
```

## 2. 画面と機能

| 画面 | 内容 |
| --- | --- |
| **ホーム** | ストリーク / 本番カウントダウン / 「今日の◯問」ワンタップ導線 / **積み上げカード（レベル・累計・定着数・マイルストーン・累積カーブ）** / **GitHub風ヒートマップ** / 分野別到達度メーター |
| **練習** | 分野選択（4分野＋全分野ミックス）・3択・解答直後に正誤＋解説（一部は**図解つき**）。**苦手な問題から優先出題** |
| **模試** | 本番形式（即時解説なし・制限時間つき）。出題比率を実際の配点に寄せ、最後に採点。合格ライン70%との比較と分野別内訳を表示 |
| **統計** | ヒートマップ / 正答率の推移 / 分野別到達度 / 学習日数 / Leitner ボックス分布 |
| **間違いノート**（`/review`） | 誤答を自動蓄積。ここだけ集中復習できる |
| **設定** | 試験日・1日のノルマ・テーマ（ライト/ダーク/端末に従う）・データリセット |

### PC / モバイル両対応
- デスクトップ（lg以上）：左サイドバー＋2カラムのダッシュボード
- モバイル：下部タブナビ
- **キーボード操作**（PC）：<kbd>1</kbd>/<kbd>2</kbd>/<kbd>3</kbd> で解答、<kbd>Enter</kbd> で次へ

### 積み上げ＝習慣化の仕組み（設計意図）
継続の動機づけとして、次の「減らない数字」だけを主役にしています。
- **レベル**（累計解答数から算出。序盤ほど早く上がる）… `src/lib/progression.ts`
- **ヒートマップ**（GitHubの草風。やるほどマスが濃くなる）… `src/components/Heatmap.tsx`
- **定着した問題数**（Leitnerボックス4以上）・**マイルストーン**（累計50問/100問…）
- ストリークが切れても責めず、「今日から再スタート」を促す文言に統一

### 弱点優先の出題ロジック（Leitner 方式）
問題ごとに正誤を記録し、5つのボックスで管理します。
- **正解** → 1つ上のボックスへ（出題頻度が下がる）
- **不正解** → ボックス1へ戻る（最も高頻度で再出題）

間違えた問題ほど繰り返し出題され、効率よく定着します。
（実装：`src/lib/leitner.ts`）

### 収録問題と試験範囲のカバー（全200問）
公式の出題内容概要（DCO：採点対象140問）の内訳に沿って配分しています。

| 分野 | 公式の問題数 | 本アプリの収録数 | 主なサブ分野 |
| --- | --- | --- | --- |
| 面談と評価 | 32問（23%） | 46問 | 初回面談・契約／メディカル歴・健康評価／体力評価／栄養の基礎 |
| プログラムデザイン | 45問（32%） | 64問 | 目標設定・動機づけ／レジスタンス・有酸素のプログラム設計／プライオメトリクス・スピード／トレーニング適応／特別な対象者 |
| エクササイズテクニック | 43問（31%） | 62問 | マシン／フリーウェイト／柔軟性／自体重・スタビリティ／パフォーマンス系／有酸素マシン／マシン以外の有酸素／オルタナティブ |
| 安全性・法的 | 20問（14%） | 28問 | 安全手順／緊急時対応／施設・器具の安全／専門職・法的・倫理 |

- 全22サブ分野をカバーし、どの範囲が未着手かは**統計 →「試験範囲のカバレッジ」**で確認できます。
- 練習モードでは分野に加えて**サブ分野を指定**して集中的に潰せます。
- 正解の位置は3択に均等分散させており、位置の勘で当たらないようにしています（`questionBank.test.ts` で自動検査）。

### 模試の出題比率・制限時間
比率は上表のとおり（`src/lib/config.ts` の `mockWeight` で変更可）。
制限時間は本番（155問・180分）を問題数に応じて比例配分します。
（実装：`src/lib/mockComposer.ts`）

### 保存層の抽象化（将来のDB化）
UI・ロジックは `StorageProvider` インターフェース（`load` / `save` / `clear`）に
のみ依存しています（`src/lib/storage/provider.ts`）。現在は `LocalStorageProvider`
実装を使用（`src/lib/storage/localStorageProvider.ts`）。将来 Supabase などに
切り替える場合は、同じインターフェースを実装したクラスを作り、
`src/lib/storage/index.ts` の `getStorageProvider()` で差し替えるだけです。

## 4. Vercel へのデプロイ手順

このアプリはリポジトリの **サブディレクトリ `apps/nsca-cpt`** にあります。
（リポジトリ直下の静的ポートフォリオサイトとは独立しています。）

1. [Vercel](https://vercel.com/) にログインし **Add New… → Project** を選択。
2. この GitHub リポジトリをインポート。
3. **Root Directory** を `apps/nsca-cpt` に設定する（重要）。
   - 「Edit」から `apps/nsca-cpt` を選択します。
4. Framework Preset は **Next.js** が自動検出されます。
   - Build Command：`next build`（既定のまま）
   - Output：静的書き出し（`output: "export"`）のため追加設定は不要です。
5. **Deploy** を押すと公開されます。

> CLI で行う場合：
> ```bash
> cd apps/nsca-cpt
> npx vercel        # 初回。プロジェクト設定を対話で作成
> npx vercel --prod # 本番デプロイ
> ```

デプロイ後、ブラウザの「ホーム画面に追加 / インストール」から PWA として
インストールでき、オフラインでも問題演習が可能です。

## 5. 【初心者向け】questions.json に1問追加する手順

問題は `src/data/questions.json` に **配列** で入っています。
ここに1件（`{ ... }`）を追加するだけで、練習・模試・弱点管理すべてに自動で反映されます。

### ステップ 1：ファイルを開く
`apps/nsca-cpt/src/data/questions.json` をテキストエディタで開きます。

### ステップ 2：末尾に1問を追加する
配列の一番最後の `}` の後ろに **カンマ `,`** を付け、次のブロックを貼り付けます。
（下の例をコピーして、内容を書き換えるのが簡単です。）

```jsonc
  {
    "id": "tech-063",
    "domain": "エクササイズテクニック",
    "topic": "フリーウェイト種目",
    "difficulty": 2,
    "question": "ここに問題文を書く。",
    "choices": [
      "選択肢A",
      "選択肢B",
      "選択肢C"
    ],
    "answerIndex": 1,
    "explanation": "ここに解説を書く。なぜ正解か・他がなぜ違うかを簡潔に。",
    "imageUrl": null,
    "videoUrl": null,
    "reference": { "edition": "第3版", "chapter": null, "page": null }
  }
```

### ステップ 3：各項目の意味と注意点

| 項目 | 説明 | 注意 |
| --- | --- | --- |
| `id` | 問題の識別子。**他と重複しない**文字列 | 例：`tech-063`。分野プレフィックス＋連番が分かりやすい |
| `domain` | 分野名。**次の4つのいずれかと完全一致**させる | `面談と評価` / `エクササイズテクニック` / `プログラムデザイン` / `安全性・法的` |
| `topic` | サブ分野。既存の値に合わせると集計に反映される | 上表「主なサブ分野」を参照。新しい値を書けば新規サブ分野として扱われる |
| `difficulty` | 難易度 | `1`〜`3` の整数 |
| `question` | 問題文 | |
| `choices` | 選択肢の配列 | 通常は3つ。順番は自由 |
| `answerIndex` | 正解の番号 | **0 から数える**（1つ目=0、2つ目=1、3つ目=2） |
| `explanation` | 解説 | 解答直後に表示される |
| `imageUrl` / `videoUrl` | 画像・動画のURL | 使わなければ `null`（将来のテクニック画像問題用） |
| `reference` | 出典（版・章・ページ） | 分からなければ `chapter`・`page` は `null` のままでOK |

> **`answerIndex` の数え方に注意**：選択肢の1つ目を正解にしたいなら `0`、
> 2つ目なら `1`、3つ目なら `2` です。

### ステップ 4：保存して確認する
1. ファイルを保存します。
2. 開発サーバーを起動（`npm run dev`）していれば自動で反映されます。
3. うまく表示されない場合、多くは **カンマの付け忘れ／付けすぎ** か
   **日本語のカギ括弧など全角記号の混入** です。
   最後の要素の後ろにはカンマを付けない点に注意してください。
4. 形式が正しいかは、ビルド（`npm run build`）が通るかでも確認できます。

### 補足：分野をまとめて増やしたいとき
`domain` の値さえ上記4分野のいずれかに一致していれば、何問でも追加できます。
分野そのものを増やす場合は `src/lib/config.ts` の `DOMAINS` に定義を追加してください。

## 6. テスト

主要ロジックには単体テスト（Vitest）を用意しています。

```bash
npm test
```

- `src/lib/leitner.test.ts` … 弱点優先の出題（ボックス昇降・苦手優先の抽選など）
- `src/lib/mockComposer.test.ts` … 模試の出題比率配分・制限時間・採点
- `src/lib/streak.test.ts` … ストリークの加算・リセット・おやすみ保護・日次集計
- `src/lib/progression.test.ts` … レベル・マイルストーン・定着数
- `src/lib/reminder.test.ts` … リマインダー（.ics）の生成
- `src/lib/questionBank.test.ts` … **問題データ自体の検査**（ID重複・選択肢数・正解位置の偏り・分野比率・サブ分野の網羅）

> 問題を追加したら `npm test` を実行してください。形式ミスや正解位置の偏りを自動で検出します。

## 7. アクセシビリティ・UX

- PCは左サイドバー＋2カラム、モバイルは下部タブナビのレスポンシブ設計
- 出題画面のキーボード操作（1/2/3・Enter）・フォーカスの可視化（`:focus-visible`）
- `prefers-reduced-motion` に対応（アニメーション抑制）
- 既定は**ライトテーマ（白背景）**。ダーク／端末追従へ切り替え可
- 絵文字は使用せず、SVGアイコン（`src/components/icons.tsx`）で統一

## 8. 解説の図解について

一部の問題には、解答直後の解説にオリジナルの図解（SVG）が表示されます
（`src/components/Illustrations.tsx`。問題IDに紐づけ）。

Web上の画像を直接埋め込む方式は
**著作権・引用要件**と**オフラインPWA動作**の両面で問題があるため採用せず、
学習ポイントを要約した自作の概念図として実装しています。
新しい問題に図を付けたい場合は `Illustrations.tsx` の `MAP` に
問題IDとコンポーネントを追加してください。
